Robotic Tissue
Stimulator & Test Frame

SolidWorks Python / Qt Mechatronics Biomechanics
What?

A 3-axis test frame I designed and built to measure how soft materials respond under compression and shear. It is aimed at soft tissues and biomaterials, with a focus on cartilage, where how the material behaves over time matters just as much as stiffness. The system controls position on all three axes and the load applied to the sample while recording the force response throughout each test.

How?

I built the system from scratch across mechanical, electrical, and software layers. I modeled custom probe mounts, load-cell mount, platen, and other parts in SolidWorks around a ball-screw motion frame. I sourced and hand-assembled the load cell, motion hardware, controller, wiring, and power components into three-axis force sensing on one controller, with correctly gauged and fused wiring, proper power distribution, and a hardware e-stop that cuts motion independently of the software. I also built the Python/Qt Windows control app with Claude Code for calibration, homing, surface finding, safety limits, live plots, test setup, and data recording.

Results?

It now works as a complete test instrument, not just a motion system. I have used it for compression, stress-relaxation, stiffness mapping, height mapping, friction, and wear tests. The wear test traces a path across a sample while holding a set normal load, and the mapping tools compare a surface, its stiffness, or its height and volume before and after a test. Results appear clearly in the app as tables and are saved to CSV for later analysis. The next step is testing on living tissue samples.

QuickStep
STEP File Trimmer

Claude Code Python (pythonocc) WebGL
What?

A STEP file viewer and trimmer for stripping large CAD assemblies down to just the parts you need. Open a full vehicle model, box-select the bodies you don't want, and export a clean STEP. I built it for myself, tired of waiting on CAD to load an entire assembly just to pull out a handful of bodies.

How?

Fully vibe coded with Claude Code. I didn't write the code by hand, but I drove the architecture and product decisions and tested it against real assemblies. Python backend using pythonocc (OpenCASCADE), a FastAPI server streaming binary geometry frames, and a single-file WebGL frontend with no libraries. Most of the work went into speed: a custom STEP text parser to skip OpenCASCADE's slow import, subprocess workers to dodge Python's GIL, and four layers of caching.

Results?

Handles a 295 MB truck assembly with 561 parts, cutting cold load from about three minutes to under one. A tool that deletes everything not visible from outside turns a long manual cleanup into a couple of clicks. Packaged it as a standalone Windows app. Easily the most complex thing I've built, and I didn't write a line of it by hand.

OptiTrack
Marker Mounts

SolidWorks 3D Printing Biomechanics
What?

Custom 3D-printed mounts that hold OptiTrack motion capture markers to bone during cadaveric testing of an SI joint implant. Two mounted to the ilium and one to the sacrum, so each rigid body could be tracked separately through the test.

How?

Modeled in SolidWorks and 3D printed. Each mount uses two ball joints so the markers can be aimed correctly for a unique specimen, then locked down with two screws driven into each ball. Rigidity was the whole challenge: any slip or flex would corrupt the tracking data. Took a few design iterations before landing on one that stayed locked over hours of testing.

Results?

The mounts held position through the full test with no drift, keeping the OptiTrack data clean from start to finish.
